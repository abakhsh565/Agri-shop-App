# Agri Shop Management System — AI Architecture Package

This package converts the supplied Final PRD into a portable engineering and AI-coding foundation.

## What this package solves
- Single source of truth for product and architecture rules.
- AI-tool portability between Claude Code, Codex, Gemini, Cursor, Windsurf, etc.
- Secure-by-design implementation rules.
- Database/API/architecture baselines.
- Architecture decision history (ADRs).
- Feature-by-feature development workflow.
