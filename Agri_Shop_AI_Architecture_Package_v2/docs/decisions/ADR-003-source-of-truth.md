# ADR-003 — Repository as AI Source of Truth

Status: Accepted

Decision: The Git repository is the persistent project memory; AI chat history is not.

Reason: Coding tools can be replaced. Requirements, architecture, decisions, security rules, and project history must remain portable.

Required artifacts: AGENTS.md, product requirements, architecture, security/threat model, API/database docs, ADRs, changelog, roadmap, and tests.
